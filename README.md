# Actividad-interactiva-mecanica
Aplicativo para aprender jugando, sober la mecanica.
Juego web de 4 niveles para aprender las leyes de Newton con ejemplos cotidianos:

1. **El bus que frena** — primera ley (inercia)
2. **El carrito del supermercado** — segunda ley (F = m·a)
3. **El salto del bote** — tercera ley (acción y reacción)
4. **La lista del celular** — la mecánica dentro del software
